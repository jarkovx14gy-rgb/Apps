MY COLLECTION — проект приложения для Android

Что умеет:
- При запуске просит PIN-код (первый PIN: 1234).
- Можно вставить ссылку и создать карточку.
- Приложение пытается автоматически получить название и картинку страницы.
- Ссылку можно открыть из карточки.
- Цену можно вписать вручную.
- Карточки и PIN сохраняются на устройстве.

Важно:
- Автоматическое получение названия/изображения зависит от сайта. Некоторые сайты блокируют такие запросы, поэтому карточка может создаться без картинки.
- PIN — простая блокировка интерфейса на этом устройстве, а не защита банковского уровня. Не используй важные пароли.

Сборка:
1. Распакуй ZIP.
2. В AndroidIDE открой действие WEB TO APP → Web Source Project to App.
3. Выбери распакованную папку проекта (в ней есть package.json и index.html).
4. Название: My Collection.
5. Package name: com.mycollection.app
6. Собери APK средствами AndroidIDE.

Проект сделан на Vite. Если AndroidIDE попросит установить зависимости, разреши это.
